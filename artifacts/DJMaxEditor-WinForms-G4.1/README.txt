DJMax Editor - WinForms-only G4.1

Run DJMaxEditor.exe.

It intentionally does not contain DJMaxEditor.Wpf.exe or
DJMaxEditor.WinFormsHost.dll.

The WinForms build retains the established save, export, conversion, chart
reader, playback, and editor paths.
